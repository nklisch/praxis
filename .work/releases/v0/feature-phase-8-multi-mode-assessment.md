# Phase 8 — Multi-mode + assessment

Retro-released into v0 on 2026-05-09. Original design: `docs/designs/phase-8-multi-mode-assessment.md`.

**Goal that shipped:** Tutor authors quizzes / homework / exams; student takes them as structured artifacts in the chat surface; server grades each item; agent narrates per-item feedback.

**Notes:** Quiz / homework / exam mode shells with five-kind item palette (multiple-choice / short-answer / free-response / math / code). Phase 17 expanded this palette to nine.

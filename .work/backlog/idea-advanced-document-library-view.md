Promote the document view from a simple flat list into a more capable library view with tabs and filters so the user can pivot between scoped and unified perspectives — e.g., "all documents," "documents in this course," "documents attached to this lesson," "documents from this bootstrap session," "documents by ingestion source / type / date," "orphaned/unscoped documents." Tabs anchor the common pivots; filters refine within a tab. Pairs with `idea-dedicated-document-view-tab` (scoped sidebar / dedicated viewer tab) and `idea-bootstrap-session-scoped-documents` (per-session scoping) — those introduce the scoping primitives; this idea is the library UI that lets a user actually navigate by them. Treat at scope time as part of a coherent "document library" surface design rather than a standalone widget.

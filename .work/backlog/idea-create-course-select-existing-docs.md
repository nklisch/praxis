The course-create entry screen currently only offers the upload path, the pack path, and the create-your-own path — there's no way to seed a new course from documents the user has already uploaded into the library. Add a "select from existing documents" affordance on the initial screen so users can pick already-indexed sources (notes, PDFs, etc.) without re-uploading. This makes the workflow coherent with the rest of the workspace, where the same documents are reused across sessions and courses.

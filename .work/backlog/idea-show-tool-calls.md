Tool calls happening in chat should be visible to the user — condensed and summarized, but shown. Today they're invisible: the student sees a pause, then the tutor's text response. They should see "looking up algebra II prerequisites…" or "grading your work…" in some compact, non-intrusive form (likely an editorial italic line in the message stream, similar to how the activity rail handles ambient progress).

Keep editorial constraints from VISION.md: no badges, no icons-as-attention-grabbers, no dopamine taps.

Unify the entry point for course-create: the "Create a course" landing screen
(currently the upload/material screen at /course-create) should be the single
landing surface for every path that starts a course-design session — onboarding
course cards, library "Create a course" CTA, top-nav, deep links, etc. Today
some paths skip the landing and drop the user directly into a fresh
course-create chat, which fragments the experience. Second piece: whatever
text the user types into the landing's prompt should be sent as the first
message immediately on arrival in the course-design view (pre-seed and start
the conversation in one click), instead of leaving them with an empty chat
they have to re-type into.

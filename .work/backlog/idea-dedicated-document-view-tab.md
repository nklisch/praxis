Add a dedicated document-viewer tab type (alongside chat/quiz/etc. tabs) so the user can open and read a single ingested document in its own workspace tab. Pair this with a scoped sidebar: the documents listed in the sidebar should reflect only the docs visible for the current scope (e.g., the current course, the current bootstrap session, or the current lesson) instead of the global document library. Together these change the document UX from "global library + modal preview" to "scoped, browsable, tab-anchored reading surface" that fits the multi-tab workspace pattern.

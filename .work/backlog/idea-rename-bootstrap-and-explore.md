"Bootstrap" and "explore" are developer-facing names that leaked into the student UX. Rename to something a student or parent would naturally read:
- "Bootstrap" mode → e.g. "Course creator" / "Set up a course" / "Plan a course".
- The explorer sub-agent — needs a name that describes what it does for the user, not what it is for the developer.

Touch points: mode names in the mode registry, mode-fragment files, button copy ("Open bootstrap mode" → "Plan a course"), tab titles, ROADMAP / SPEC references that surface to the user.

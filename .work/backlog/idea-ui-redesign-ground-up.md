Re-examine Praxis's design and UI from the ground up, treating the current shell as a candidate for replacement rather than an extension point. Use the `/ux-ui-design` plugin end-to-end — `/ux-ui-design:palette` to redefine the visual system (color tokens, typography, spacing), `/ux-ui-design:screens` to reimagine the major surfaces (chat workspace, library, progress map, configure, the per-mode tab bodies), and `/ux-ui-design:flows` to rethink the cross-screen journeys (session open, bootstrap, mode switching, assignment spawn → parent notification). The goal is alignment on a fresh visual + interaction direction before any production rework, so the existing editorial primitives and tab isolation patterns are inputs to question, not constraints to honor.

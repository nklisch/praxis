The prompt menu (the customizable system-prompt fragment editor in configure mode) doesn't use the full horizontal space available — it appears constrained to a narrower column while the surrounding layout has room to spare, forcing long fragment templates to wrap or scroll unnecessarily. Loosen the max-width constraint (or switch to a fluid layout) so the editor expands to fill the available editorial column, making long prompt templates easier to read and edit in place.

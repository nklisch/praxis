During course creation, the drafting agent's actions are largely opaque to the user — there's no visible trace of what the agent is doing (which units / lessons / assessments it's adding, which tools it's calling, where it is in the plan). Users should be able to see the drafter's activity in some form during the run: a streamed action log, progress indicators, a working canvas, or activity-strip-style entries. Worth deciding how much of the agent's loop to surface and where (chat surface vs side panel vs strip).

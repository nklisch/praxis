When attaching documents (e.g., during course bootstrap / ingestion / configure flows), let the user pick multiple files in a single dialog, and ideally select a whole folder at once instead of attaching files one-by-one. Today the attach flow appears to be single-file; a multi-file picker and a folder picker would reduce friction when seeding a course from a textbook split across many PDFs/PPTXs or a directory of materials.

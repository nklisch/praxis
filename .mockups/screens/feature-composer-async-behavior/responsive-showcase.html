What's adapting: not the components — the .chat-surface wrapper changes max-width via the --wide / --medium / --narrow modifier, and components inside use @container chat (max-width: ...) queries against the surface. At medium, padding tightens. At narrow, the composer hint strip stacks vertically. Same DOM, same component classes, same JS. The only thing that changes per context is one modifier on the surface wrapper. Course-create wraps its chat panel in chat-surface chat-surface--medium; a future mobile / sidebar tutor uses chat-surface--narrow; teach window uses the default --wide.

Composer · async behavior feature-composer-async-behavior · 4 states + responsive showcase

The composer never locks while a tutor turn is in flight. Messages queue inline as ghost turns with per-item edit / remove; .composer__send takes .composer__send--stop modifier in place during in-flight; failures surface inline first and escalate to .status-strip if unattended. Composed against .chat-surface so the same components work in teach, course-create, and future sidebar contexts.

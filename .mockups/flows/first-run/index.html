First-run onboarding

Full-screen onboarding journey. The student sees this before the main app chrome is visible. Three steps: welcome, engine picker (with Claude Code sign-in sub-step), and course picker.

01
Welcome
Opening card — restrained greeting, italic serif title, continue / skip actions.
 02
Engine picker — default (Direct API)
Engine select + API key field. Mono kicker labels. Back / Skip / Continue actions.
 03
Engine picker — Claude Code selected
No API key; sign-in row with brick accent button. After auth: quiet "Signed in ✓" badge.
 04
Course picker
Three full-width cards (Algebra, Biology, Syllabus) with mode-tint dots, italic labels. Clicking any launches a bootstrap session.

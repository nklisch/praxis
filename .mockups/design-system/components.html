About this showcase

The locked component contract for Praxis. Tier-1 editorial primitives + the broad 6-pack tier-2 domain widgets, every component in every state. Sharpening: codify-as-is, tighter consistency — hairlines where they already live, primary accent used freely on the dominant action of every surface, status colors paired with badge chrome, 2px-border tab indicator on the active tab. Downstream mocks link this stylesheet; production CSS modules adopt these classes during the migration sweep feature.
